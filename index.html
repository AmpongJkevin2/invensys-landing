What It Does

Built for Real-World
Engineering Workflows

Every feature was designed to handle actual inventory management challenges in academic and engineering environments.

SQLite Database

Zero-config, file-based database. All inventory data is stored locally — no server needed. Supports multiple tables for different departments or lab rooms.

Built-in · Offline-first

Dashboard & Charts

Visualize inventory health at a glance. Interactive pie and bar charts show status distribution and record counts across all your tables in real time.

Chart.js · Real-time

Multi-Format Export

Export your entire inventory in three formats — Excel (.xlsx), CSV, and JSON — for reporting, backups, or integration with other tools.

Excel · CSV · JSON

Role-Based Access

Granular permission system with admin and user roles. Control who can view, add, edit, delete, import, or export — per user, per action.

Admin · User · Permissions

Batch Update

Update multiple records simultaneously. Apply status changes or field edits across an entire table selection without touching each entry individually.

Bulk Edit · Time-saving

Recovery Manager

Accidentally deleted something? The built-in recovery system keeps a history of changes and allows data to be restored without manual backups.

Undo · History · Safe

Smart Search

Instant keyword search across all columns. Filter by any field — item name, status, quantity, or custom attributes — with live results as you type.

Live Filter · All Columns

Excel Import

Seed your system by uploading an existing Excel spreadsheet. InvenSy converts it to a database table automatically — no manual entry required.

XLSX Upload · Auto-convert

Audit History

Every create, edit, and delete action is timestamped and logged. Full traceability for accountability — know exactly what changed and when.

Logged · Timestamped
The Flow

How InvenSy Works

From raw data to actionable insights in four simple steps.

01

Import or Add Data

Upload an Excel file or manually add records through the built-in form. InvenSy converts your spreadsheet into a structured SQLite database automatically.

# Auto-convert Excel → SQLite df = pd.read_excel("inventory.xlsx") df.to_sql(table, conn)
02

Search, Filter & Manage

Use the powerful search bar to find any item instantly. Edit individual records or run a batch update across hundreds of entries in one go.

# Smart search query SELECT * FROM items WHERE name LIKE "%arduino%"
03

Visualize on Dashboard

The dashboard auto-generates charts from your live data — status distributions, record counts, and field breakdowns — all updated in real time.

# Live chart data injection stats = db.get_status_counts() render("dashboard", stats=stats)
04

Export & Report

Generate reports in Excel, CSV, or JSON with a single click. Share inventory snapshots with faculty, administration, or for archiving purposes.

# One-click export df.to_excel("report.xlsx") df.to_csv("backup.csv")
