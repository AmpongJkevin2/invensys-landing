What It Does

Built for Real
Library Workflows

Every feature designed for the UCC engineering library's daily operations.

01

SQLite Database

Zero-config local database. All book records stored in a single file — fast, reliable, no server needed.

Offline · File-based
02

Role-Based Access

SuperUser/Admin with full control, Staff with limited permissions. OJT students get restricted access only.

Admin · Staff · OJT
03

Multi-Format Export

One-click export to Excel (.xlsx), CSV, and JSON. Generate reports and backups instantly.

Excel · CSV · JSON
04

Batch Update

Update multiple book records at once. Change status, publisher, or any field across dozens of entries in seconds.

Bulk Edit · Fast
05

Smart Search

Search by title, author, accession number, year, publisher — any column. Results appear instantly.

Live · All Columns
06

Recovery Manager

Accidentally deleted a record? Built-in recovery system restores it from history. No data is ever truly lost.

Undo · History
07

Visual Dashboard

Interactive charts showing status distribution and book counts. Configurable chart types: pie, bar, or line.

Chart.js · Real-time
08

Excel Import

Upload an existing Excel spreadsheet and InvenSy auto-converts it to a database table. No manual entry needed.

XLSX Upload · Auto
09

Audit History

Every add, edit, and delete is timestamped and logged. Full accountability trail for every user action.

Logged · Timestamped
The Flow

How InvenSy Works

Four steps from raw spreadsheet to managed library.

01

Import or Add Books

Upload an Excel spreadsheet of existing library records — InvenSy auto-converts it. Or add individual books via the built-in form.

# Excel → SQLite in one line df = pd.read_excel("books.xlsx") df.to_sql(table, conn)
02

Search, Filter & Edit

Find any book instantly by title, author, or accession number. Edit single records or run a batch update across hundreds at once.

# Search across all columns SELECT * FROM books WHERE title LIKE "%calculus%"
03

View Dashboard

The dashboard auto-generates live charts — status breakdowns, record counts per table. Configurable between pie, bar, and line charts.

# Live chart from DB stats = db.get_status_counts() return render("home", stats=stats)
04

Export & Report

Generate an Excel, CSV, or JSON snapshot of the entire library with one click. Perfect for faculty reports or archiving.

# One-click export df.to_excel("report.xlsx") df.to_csv("backup.csv")
